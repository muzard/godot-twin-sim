# st1-ambush: a squad runs into an ambush

The st1 ambush (backlog 0004): the reference squad of nine, in a wedge, starts in the forest on the second leg of the
st1 corridor and is ordered to B, across a field. Three red fighters with a machine gun lie prone just inside the west
edge of the copse where the route leaves the field, watching the field. Everyone fires freely at enemies it has
spotted.

The map is st1's (`"world": "../st1/world"`); see `../st1/README.md` for the area, the data sources and the required
MML attribution. Run it with `./dev replay st1-ambush` (add `--godot` to watch it).
